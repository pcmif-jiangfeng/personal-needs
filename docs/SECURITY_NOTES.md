# 安全说明

审计日期：2026-09-14

## 已确认

- 应用、测试和 README 中未发现疑似 API Key、Secret、Token、密码或认证凭据。
- SQLite 查询使用参数绑定；排序字段由服务端白名单控制。
- 服务默认监听 `127.0.0.1`，不对局域网或公网开放。
- `.env` 与 `data/` 已被 Git 忽略；`.env.example` 不含真实值。
- API 响应不返回环境变量或数据库文件路径之外的敏感配置。

## 公开部署前的高优先级事项

1. 增加身份验证与访问控制。当前没有用户边界，任何能访问服务的人都能读取、修改、导出和删除全部数据。
2. 将数据从单机 SQLite 迁移至具有备份与访问控制的托管数据库，或至少设计可靠备份与恢复流程。
3. 在 HTTPS 反向代理之后运行，并添加适合实际部署域名的 CSP、CSRF 和限流策略。

## 已知限制

当前服务面向单用户本机使用。它不是多用户互联网服务；不要通过端口转发、公共隧道或将 `HOST` 改为 `0.0.0.0` 后直接暴露真实数据。
