# App 化路线

## 路线 A：响应式 Web

当前最合适。现有界面已经能在小屏幕下改为纵向布局，继续通过手机浏览器访问即可。维护成本最低，数据继续由本机 SQLite 管理。

## 路线 B：PWA

难度：中等。需要添加 Web App Manifest、图标、Service Worker、离线缓存策略和安装提示。核心前提是先明确数据同步策略：当前 SQLite API 只能在运行应用的设备上使用，PWA 不会自动获得多设备数据同步。

建议时机：完成一次真实用户使用周期，并明确离线与同步需求后。

## 路线 C：Android / iOS 包装

难度：中高。可在 Web 体验稳定后用 Capacitor 包装；届时需要决定本地数据库实现、备份、应用签名、商店发布和移动端权限策略。

建议时机：PWA 或移动浏览器使用频率已被验证，且确实需要原生通知、离线数据库或商店分发时。
